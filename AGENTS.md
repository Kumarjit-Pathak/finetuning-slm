# Project Agents

Pipeline: **developer → reviewer → documentation + visualization → humanizer**

| Agent | Role |
|---|---|
| `developer` | Implements notebooks/code per `slm-finetuning-plan.md` |
| `reviewer` | Audits implementation against plan (PASS/FAIL) |
| `documentation` | Creates/updates `docs/` HTML pages (fun tone, Tailwind CSS) |
| `visualization` | Creates SVGs in `docs/images/` using project color palette |
| `humanizer` | Final polish — readable, witty, technically accurate |
