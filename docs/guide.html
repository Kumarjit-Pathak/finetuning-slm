What you need before you start

Skills
Comfort with Python

You should recognize a dictionary. You do not need to have written a transformer from scratch. If you can pip install things, you can start.

Hardware
A laptop

Apple Silicon works. NVIDIA GPU with 6 GB+ works. Google Colab free tier works. A very patient CPU technically works, but you will grow older.

Time
Four hours minimum

The beginner track fits in a slow Saturday. The advanced track is a weekend project. Skimming plus running is the recommended pace.

FAQ

Do I have to run every notebook to learn the material?

No. Reading and running are both legitimate ways through this. The techniques pages summarize every notebook in five minutes if you want the shortcut.

My laptop does not have a GPU. Am I doomed?

No, but plan for coffee. The 135M model runs on CPU. Training is slower by roughly an order of magnitude. Notebook 05 (QLoRA) helps on any 6 GB+ GPU. Colab free tier is a valid path.

Which technique should I actually use in production?

LoRA or QLoRA, most of the time. See the Which Method? page for a 4-question wizard that picks one for you.

Is 135M really enough for real work?

For structured output, format learning, and narrow tasks — yes. For creative style transfer and general reasoning — no. The tutorial reports the capacity wall honestly. The techniques scale up to 7B and 70B with no code changes.

The checklist reset when I opened another browser. Why?

Progress is stored in the current browser's localStorage. Different browsers, different lists. This is by design, because we do not run a server, and because we do not want your email address.
